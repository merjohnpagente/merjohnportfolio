Featured Project

FitCore Gym Management System

A full gym management system with membership tracking, class scheduling, and trainer management.

Role: Full-Stack Developer
Stack: HTML, CSS, JavaScript
Status: Deployed

Overview

FitCore is a comprehensive gym management platform built to streamline operations for fitness centers. The system handles member registrations, membership plans, class schedules, trainer assignments, and attendance tracking — all through a clean, responsive web interface.

Key Features

  • Member management (CRUD, search, filters)
  • Membership plans with automated expiry tracking
  • Class scheduling with trainer assignment
  • Attendance logging and reporting
  • Responsive dashboard for admin & trainers

Challenges & Solutions

Real-time schedule conflicts: Implemented client-side validation with visual calendar feedback to prevent double-bookings.

Data persistence without backend: Used localStorage with structured schemas, enabling offline-capable demo deployment.
